# 🛒 Ecommerce Static Website

A responsive **Ecommerce static website** built using **HTML, CSS, and
JavaScript**. This project demonstrates a modern shopping UI with
product sections, clean layout, and responsive design.

🌐 **Live Demo:**\
https://ecommercestaticwebsiteprateek.netlify.app/

---

## 📌 Features

- Responsive ecommerce layout
- Product listing section
- Clean and modern UI
- Navigation bar and product categories
- Fully responsive for desktop and mobile
- Optimized static website

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Netlify (Deployment)**

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1️⃣ Clone the repository

```bash
git clone https://github.com/prateek205/e-com.git
```

### 2️⃣ Open the project

Open the project folder and run the **index.html** file in your browser.
